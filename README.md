# Word Master
A web game based off of Wordle, featuring new modes with varying difficulty.

## Features
* Primary gameplay inspired by Wordle
* New modes with different word lengths
* Basic account system and stat tracking
* View win rates, guess counts, and performance per-mode

## Layout

### Main Page - Main Menu
The main page of the site will be the main menu, where you can select your mode, login/create your account, and, of course, start the game.

### Secondary Page - Game
This is where the game will take place.
As you would expect, the letter blocks from Wordle will appear and be filled in and colored as you guess.
This page can be reused for the different modes, adjusting to word length and how many guesses are allowed.

### Third Page - Statistics
After logging in, you can access your stats to see how you've performed.
For stats, the game tracks your wins and losses, how many guesses your attempts take, as well as calculating things like win rate and your average guesses.
There are options to filter your stats per-mode, so you can view stats for words of 6 characters in length, specifically, if you wanted.
